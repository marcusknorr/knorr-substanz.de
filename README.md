# Marcus Knorr – Paket für GitHub Pages

## Erneut hochladen
1. ZIP auf Ihrem Computer vollständig entpacken.
2. Im Repository den bisherigen Ordner `htdocs` einschließlich `private` und PHP-Dateien entfernen. Alte START_HIER.txt und PRUEFNOTIZEN.md ebenfalls entfernen; dieses README ersetzt sie.
3. Im Hauptverzeichnis des Repositorys „Add file → Upload files“ wählen.
4. Den INHALT dieses entpackten Pakets hochladen: index.html, impressum.html, datenschutz.html, style.css, kontakt.js, den Ordner assets sowie Lizenz und README. Nicht die ZIP und nicht einen zusätzlichen umschließenden Ordner hochladen.
5. „Commit changes“ bestätigen.
6. Unter Settings → Pages: Deploy from a branch, main, / (root), Save. Bei bereits passenden Einstellungen nichts ändern.
7. Nach erfolgreicher Veröffentlichung https://marcusknorr.github.io/knorr-substanz.de/ öffnen und ggf. neu laden.

Die Datei index.html muss neben assets direkt auf der obersten Ebene liegen.
.nojekyll kann mit hochgeladen werden; bei diesen einfachen Dateien ist sie nicht zwingend.
Dieses Paket enthält keinen PHP-Code und keine Zugangsdaten. Falls Sie zuvor ein echtes Passwort in das öffentliche Repository geladen haben, ändern Sie es bei IONOS. Nur Löschen beseitigt es nicht aus der Git-Historie.

## Kontaktfunktion
„E-Mail vorbereiten“ öffnet ein vom Besucher eingerichtetes Mailprogramm. Der Besucher muss selbst absenden. „Text kopieren“ unterstützt Webmail und lange Nachrichten. Ohne JavaScript bleiben Telefon und der direkte E-Mail-Link nutzbar. Es gibt keinen direkten Formularversand und keinen eingebundenen Formulardienst. Kein Zustellungsnachweis wird vorgetäuscht.

## Eigene Domain
Zunächst die github.io-Adresse prüfen. Das Paket enthält bewusst keine CNAME-Datei, damit keine Weiterleitung auf eine noch nicht eingerichtete Domain ausgelöst wird. Die Domain knorr-substanz.de anschließend in Settings → Pages und beim Domainanbieter einrichten, danach HTTPS aktivieren. Eine Kündigung des Webspaces darf nicht versehentlich Domain oder IONOS-Mailpostfach beenden.
